# ユニットテストケース一覧

## 目的

本ドキュメントは、`CLAUDE.md` のテスト方針（単体テストはVitestを用い、組合せ表自動生成・開始ホール自動割当・スコア自動計算（ホールインワン変換を含む）・順位決定ロジックなど「コアロジック」に該当する、間違えやすい機能を重点的にカバーする）に基づき、単体テストで検証すべきケースを列挙する。

- 対象ロジックの一次情報源は `docs/要件定義書.md`（3.1〜3.7、4章バックアップ）。
- 本書はテストケースの仕様である。実行可能なテストコードは、対象ロジックの `*.ts` と同じディレクトリの `*.test.ts` として実装する。
- 実行コマンド：`npm test`（Vitest）。
- 順位の決定方法は以下のとおり（要件定義書3.7、2026-11-17 運用者指示により明確化）。
  - 個人戦：1. トータルスコアが小さい、2. 年齢が上、3. じゃんけん
  - チーム戦（平均）：1. チームの平均スコアが小さい、2. チームの合計年齢が上、3. じゃんけん
  - チーム戦（合計）：1. チームの合計スコアが小さい、2. チームの合計年齢が上、3. じゃんけん
