# リリースノート

各リリース（バージョンタグ）ごとの内容を記録する。リリースコミット作成時（`CLAUDE.md`「Gitワークフロー」参照）に、該当バージョンのエントリを本ファイルの先頭に追記すること。

## v1.0.0 (2026-11-19)

- 初版
- 主な機能
  - 管理者ログイン（ID・パスワードの変更、閲覧モード）
  - 大会情報・競技情報・選手情報の登録・編集・削除（生年月日の西暦・和暦入力、パーティ固定、不参加）
  - 組合せ表の自動作成（シャッフル／チーム方式）と開始ホールの自動割当、開始ホール・開始グループの変更
  - スコア表の生成とスコア入力（ホールインワン変換、ラウンド合計・総合合計の自動計算）
  - 順位表の作成（個人戦、チーム戦（平均・合計）、同順位のじゃんけんによる手動確定）
  - 大会の終了・再開（終了中は編集・スコア入力・順位表作成・手動確定を禁止）
  - バックアップ（手動・ログアウト時）と復元（最大20件、期間絞り込み）
- 配布
  - macOS版（Apple シリコン用・Intel用の .dmg）、Windows版（.exe インストーラ）
  - インターネット接続不要・Node.js等の追加インストール不要。操作手順書を同梱（メニュー「ヘルプ」→「操作手順書を開く」）
- 既知の制限
  - macOSはApple Developer IDによる署名・公証を行っていないため、インストール後に検疫属性の解除（`xattr -cr`）が必要（インストール手順書参照）
  - Windowsはコード署名を行っていないため、インストール時にSmartScreenの警告が表示される（「詳細情報」→「実行」）
  - データ出力（Excel）・参加者向け閲覧URL・WEB公開ページは将来対応
- テスト結果：ユニットテスト195件・結合テスト147テスト（157ケース）・E2Eテスト6シナリオ、全件OK
