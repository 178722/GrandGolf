# 操作手順書

本書は「グランドゴルフしようよ」を使って大会を運営する方（大会運営者・管理者）向けの操作手順書です。パソコンの操作に慣れていない方でも読み進められるよう、画面に表示されるボタンや項目の名前をそのまま「」で囲んで書いています。

- アプリのインストール方法と、最初にログインするためのID・パスワード（初期管理者アカウント）は、別紙の「インストール手順書」（Windows版／Mac版）を参照してください。
- 本書は、アプリのメニュー「ヘルプ」→「操作手順書を開く」からいつでも開けます（「1. アプリの起動とログイン」の「操作手順書を開く」参照）。
- 画面の細かな仕様は `docs/画面仕様書.md`、機能の決まりごとは `docs/要件定義書.md`、ことばの意味は `docs/用語集.md` にまとめています（いずれも開発用の資料で、アプリには同梱していません。必要な場合は導入時の担当者にお問い合わせください）。

---

## はじめに

### このアプリでできること

「グランドゴルフしようよ」は、グランドゴルフ大会の受付から順位発表までを、運営者のパソコン1台で行うためのアプリです。インターネットにつながっていなくても使えます。

1. 大会の登録（大会名・開催日・開催場所）
2. 競技情報の登録（ラウンド数・ホールインワンの扱い・パーティの人数・チーム戦の有無など）
3. 選手の登録（選手名・生年月日・チーム名など）
4. 組合せ表の作成（パーティ分けと、各パーティがどのホールから回り始めるか＝開始ホールを自動で決めます）
5. スコアの入力（ホールごとの打数。合計は自動で計算されます）
6. 順位表の作成（個人戦・チーム戦）
7. バックアップと復元（データを保存しておき、必要なときに元に戻せます）

> Excelファイルへのデータ出力は、今後の対応予定です。現在のアプリにはありません。

### 本書で使うことば

| ことば | 意味 |
|---|---|
| 大会 | 1回の大会（例：「定例会」）。大会ごとに競技情報・選手・組合せ表・スコア・順位表を持ちます |
| 競技情報 | ラウンド数やパーティの人数など、その大会の競技のルール。1つの大会に1件だけ登録します |
| ラウンド | コース（1番〜8番の8ホール）を1周すること。1大会で1〜5ラウンド行えます |
| ホール | コースの1番〜8番の各ホール |
| パーティ | 一緒にコースを回る組（1〜6人） |
| パーティ番号 | パーティにつけられた番号 |
| 開始ホール | そのパーティが最初に打ち始めるホール（1〜8） |
| 開始グループ | 同じ開始ホールから出るパーティの順番（1, 2, 3…）。パーティ番号の小さい順につきます |
| 固定パーティ | 選手を登録するときに「パーティ固定」にして、パーティ番号を指定した選手のパーティ |
| 打数 | 1つのホールで打った回数（1〜99） |
| ホールインワン | 1打でホールに入ること（打数1）。設定によって、打数1を別の点数（例：-2）に置き換えて計算します |
| じゃんけん待ち | 同じ成績で、アプリでは順位を決められない状態。じゃんけんの結果を管理者が入力します |
| 閲覧モード | ID・パスワードなしで画面を見るだけのモード。登録・変更はできません |
| バックアップ／復元 | データを保存しておくこと／保存しておいたデータに戻すこと |

より詳しい意味は、開発用の資料 `docs/用語集.md` にまとめています。

### 画面の基本

- **ボタン**：枠で囲まれた文字（例：「保存」）をクリックすると操作が行われます。
- **灰色で押せないボタン・入力欄**：その時点では操作できないことを表します。マウスを重ねると理由が表示されるものがあります（例：「閲覧モードのため変更できません」）。
- **赤い文字**：入力の誤りや、操作できない理由を表します。内容を読んで入力し直してください。
- **緑の文字**：「保存しました」など、操作が成功したことを表します。
- **確認の小さな画面（ダイアログ）**：大事な操作の前には「〜しますか？」と確認の画面が出ます。よければ右側のボタン（「作成する」「削除する」など）、やめる場合は左側のボタン（「キャンセル」「しない」）を押します。
- **「エラー」の画面**：操作ができなかった理由が表示されます。読んだら「閉じる」を押してください。
- **「* 」印**：入力が必須の項目です。

### 大会当日までのおおまかな流れ

1. ログインする（1章）
2. 大会を登録する（2章）
3. 競技情報を登録する（3章）
4. 選手を登録する（4章）
5. 組合せ表を作成し、パーティと開始ホールを確認する（5章）
6. 「大会を開催する」で組合せ・スコア表を開き、スコアを入力する（6章）
7. 順位表を作成し、同じ成績の人がいれば、じゃんけんの結果を入力する（7章）
8. 大会を終了する（8章）
9. バックアップを作成してログアウトする（10章・11章）

## 1. アプリの起動とログイン

### アプリを起動する

1. **Windows**：デスクトップまたはスタートメニューの「グランドゴルフしようよ」をダブルクリック（クリック）します。
   **Mac**：「アプリケーション」フォルダ（またはLaunchpad）の「グランドゴルフしようよ」をクリックします。
2. 数秒〜十数秒待つと、ログイン画面が表示されます。
   - アプリはすでに起動している場合、もう一度起動しても新しい画面は開かず、開いている画面が前に出てきます。

### ログインする

1. ログイン画面の「ID」欄にID、「パスワード」欄にパスワードを入力します。
   - 初めて使うときのID・パスワードは、「インストール手順書」の「4. 初回起動」に書かれています。
2. 「ログイン」ボタンを押します。
3. 「大会一覧」の画面が表示されれば、ログインできています。
   - 「IDまたはパスワードが正しくありません」と表示された場合は、入力を確かめてやり直してください。大文字・小文字も区別されます。
   - パスワードは8文字以上です。

### ログインID・パスワードを変更する

初めて使うとき（初期のID・パスワードのとき）は、すぐに自分たちだけが知っているID・パスワードに変更してください。

1. ログイン画面の下にある「ログイン情報を変更する」をクリックします（ログインしていなくても変更できます）。
2. 「ログイン情報の変更」の画面が開きます。次の4つをすべて入力します。
   - 「現在のID」「現在のパスワード」（本人確認のため、今のID・パスワードを入力します）
   - 「新しいID」
   - 「新しいパスワード（最低8文字）」
3. 「変更する」ボタンを押します。
4. 「ログイン情報を変更しました。」と表示されたら完了です。「閉じる」を押し、新しいID・パスワードでログインしてください。
   - 「現在のID・パスワードが正しくありません」と表示された場合は、今のID・パスワードの入力を確かめてください。
   - 新しいID・パスワードは、紙に書くなどして大切に保管してください。忘れた場合は「ID・パスワードを忘れた場合」を参照してください。

### 閲覧モードで見る

ID・パスワードが分からない方でも、画面を見るだけなら「閲覧モード」で入れます。

1. ログイン画面の「閲覧モードで見る（ID・パスワード不要）」ボタンを押します。
2. 大会一覧の画面が表示されます。画面上部のアプリ名の横に「閲覧モード」と表示されます。
3. 閲覧モードでは、大会・競技情報・選手情報・組合せ表・スコア・順位表をすべて**見ることができますが、登録・変更・削除・組合せ表の作成・スコア入力・順位表の作成・バックアップ・復元などはできません**（ボタンが灰色で押せません）。
4. 管理者として操作したい場合は、いったん「ログアウト」してから、ID・パスワードでログインし直してください。

### 操作手順書を開く

アプリのメニュー「ヘルプ」→「操作手順書を開く」を選ぶと、本書が開きます。

- **Windows**：アプリの画面ではメニューが隠れています。キーボードの **Alt** キーを押すと、画面の上にメニュー（「ファイル」「編集」「表示」「ヘルプ」）が表示されます。
- **Mac**：画面のいちばん上のメニューバーに「ヘルプ」があります。
- 本書は、パソコンで「.md」ファイルを開くように設定されているアプリ（メモ帳やテキストエディットなど）で開きます。開けない場合は「操作手順書を開けません」と表示されます。その場合は、インストール時にお渡しした `操作手順書.md` を直接開いてください。

### アプリを終了する

- 画面右上（Macは左上）の「×」（閉じる）ボタンでウィンドウを閉じると、アプリが終了します。
- 終了する前に、できるだけ「ログアウト」してバックアップを作成してください（11章）。

## 2. 大会の登録・編集・削除

### 大会を新しく登録する

1. 大会一覧の画面で「+ 新規作成」ボタンを押します。
2. 「大会情報登録」の画面で、次の項目を入力します（すべて必須です）。
   - 「大会名（最大50文字）」：例）定例会
   - 「開催日」：カレンダーから選びます。最初は今日の日付が入っています。**開催日は、選手の年齢を計算する基準日になります**（順位表の年齢の比較に使います）。
   - 「開催場所（最大50文字）」：例）グラウンド
3. 「保存」ボタンを押します。
   - やめる場合は「キャンセル」を押すと、大会一覧に戻ります。
4. 保存すると、その大会の画面（大会情報）に切り替わります。画面上部に大会名と「進行中」の表示、その下に「組合せ表を作成する」「大会を開催する」「大会を終了する」のボタン、さらに「大会情報」「競技情報」「選手情報」のタブ（見出し）が表示されます。

### 大会の画面の開き方

- 大会一覧の表で、大会の行（大会名など）をクリックすると、その大会の「大会情報」画面が開きます。
- どの画面からでも、画面左上のアプリ名「グランドゴルフしようよ」、または「← 大会一覧」をクリックすると大会一覧に戻れます。
- 大会一覧は、開催日の新しい順に並んでいます。

### 大会情報を変更する

1. 大会の画面で「大会情報」タブを開きます。
2. 「大会名」「開催日」「開催場所」を書き換えて「保存」を押します。「保存しました」と表示されれば完了です。
   - 書き換えをやめて元に戻したいときは「キャンセル」を押します。
   - 大会が「終了」のときは変更できません（8章）。

### 大会を削除する

1. 大会一覧の画面で、削除したい大会の行の右端にある「削除」ボタンを押します。
2. 「大会を削除しますか？」と表示されます。内容を確認し、よければ「削除する」を押します。
   - **注意**：大会を削除すると、その大会の競技情報・選手情報・組合せ表・スコア表・順位表がすべて削除され、元に戻せません（バックアップから復元する方法はあります。10章）。
   - 大会が「終了」でも削除できます。

## 3. 競技情報の登録

大会を登録したら、次に競技のルールを登録します。**競技情報を登録しないと、組合せ表を作成できません。**

1. 大会の画面で「競技情報」タブを開きます。
   - まだ登録していない大会では「競技情報が未登録です。内容を確認して「保存」してください。」と表示され、最初の値（ラウンド数1など）が入っています。
2. 次の項目を設定します。

| 項目 | 設定のしかた | 最初の値 |
|---|---|---|
| ラウンド数 | 1〜5から選びます | 1 |
| ホールインワン時のスコア変換 | ホールインワン（打数1）を別の点数に置き換える場合は「変換あり」にチェックを入れます | 変換あり |
| ホールインワン時のスコア変換値 | 「変換あり」のとき、打数1を何点として計算するかを -5〜1 から選びます | -2 |
| パーティの最大人数 | 1パーティの人数の上限を 1〜6 から選びます | 6 |
| パーティの決定方法 | 「チーム」または「シャッフル」を選びます（必須） | 未選択 |
| チーム戦 | チームの順位も出す場合は「チーム戦あり」にチェックを入れます | なし |
| チーム戦の順位決定方法 | 「チーム戦あり」のとき、「合計」または「平均」を選びます | 未選択 |

3. 「保存」ボタンを押します。「保存しました」と表示されれば完了です。

### 項目の説明

- **ホールインワン時のスコア変換**：例えば変換値が -2 のとき、打数1のホールは「1打」ではなく「-2」としてそのラウンドの合計に入ります（1打に-2を足すのではなく、-2に置き換えます）。
- **パーティの決定方法**
  - 「チーム」：同じチーム名の選手を、チームを分けずに同じパーティにします。1チームの人数が「パーティの最大人数」を超えると組合せ表を作れません。この場合、選手登録で「チーム名」が必須になります。
  - 「シャッフル」：チームに関係なく、くじ引きのように選手を混ぜてパーティを作ります。各パーティの人数がなるべく同じになるように分けます。
- **チーム戦の順位決定方法**
  - 「合計」：チームの選手のスコアを合計した数で順位を決めます。
  - 「平均」：チームの選手のスコアの平均で順位を決めます（チームの人数が違うときに使います）。

### 注意

- 組合せ表を作成した後で競技情報を変更すると、「組合せ表・スコア表の削除確認」の画面で「既存の組合せ表・スコア表を削除し、再生成が必要になります。変更しますか？」と表示されます。「変更する」を押すと、組合せ表・スコア表が削除されて保存されます（「保存しました（組合せ表・スコア表を削除しました）」と表示されます）。その後、組合せ表をもう一度作成してください（5章）。
- **スコアが1件でも保存されると、競技情報は変更できなくなります**（「試合結果が登録されているため変更できません」と表示されます）。
- 大会が「終了」のときは変更できません。

## 4. 選手情報の登録

### 選手を登録する

1. 大会の画面で「選手情報」タブを開きます。
2. 「+ 新規登録」ボタンを押すと、「選手情報の新規登録」の画面が開きます。
3. 次の項目を入力します。

| 項目 | 入力のしかた |
|---|---|
| 選手名（最大10文字）* | 選手の名前。同じ大会の中で同じ名前は登録できません（同姓同名の場合は「山田太郎A」のように区別してください） |
| 生年月日 * | 下の「生年月日の入力のしかた」を参照 |
| チーム名（最大10文字） | 所属チームの名前。競技情報で「チーム戦あり」または、パーティの決定方法が「チーム」のときは必須（* が付きます）です。それ以外のときは空欄でもかまいません |
| パーティ固定 | 特定のパーティに入れたい選手は「固定」にチェックを入れます |
| パーティ番号（1〜99） | 「固定」にチェックしたときだけ入力できます。入れたいパーティの番号です |

4. 入力が終わったら、次のどちらかを押します。
   - 「保存して閉じる」：入力した選手を一覧に追加して、画面を閉じます。
   - 「追加して続けて登録」：入力した選手を一覧に追加し、画面を開いたまま次の選手を入力できます（「「○○」を一覧に追加しました。続けて入力できます。」と表示されます）。選手名と生年月日は空欄に戻り、チーム名・パーティ固定・パーティ番号は前の選手と同じ値が残ります。同じチームの選手を続けて入力するときに便利です。入力を終えたら「閉じる」を押します。
5. **最後に、一覧の右上にある「保存」ボタンを必ず押してください。**
   - 「保存して閉じる」「追加して続けて登録」は一覧に並べるだけで、まだ保存されていません（画面にも「※一覧の「保存」ボタンを押すまでサーバーには反映されません。」と表示されます）。
   - 保存していない変更があるときは、一覧の右上に「未保存の変更があります」と表示されます。
   - 「保存しました」と表示されれば完了です。

### 生年月日の入力のしかた

生年月日は、次のどちらかの形で、**半角の数字と記号**で入力します。

| 形 | 入力例 | 意味 |
|---|---|---|
| 西暦 年/月/日 | `1971/05/24` または `1971/5/24` | 1971年5月24日 |
| 和暦 元号の頭文字＋年.月.日 | `S46.05.24` または `S46.5.24` | 昭和46年5月24日 |

- 元号の頭文字は、**S**＝昭和、**H**＝平成、**R**＝令和 です（小文字の s・h・r でもかまいません）。
- 正しく読み取れると、入力欄の下に「→ 1971/05/24」のように西暦で表示されます。表示されないときは、入力の形を確かめてください。
- 実際にない日付（例：2月30日）や、その元号の期間外の日付（例：S64.02.01）は入力できません。
- 一覧では、生年月日は西暦（例：1971/05/24）で表示されます。

### 選手を修正する

1. 一覧の選手の行の「編集」ボタンを押します。
2. 「選手情報の編集」の画面で書き換えて、「保存して閉じる」を押します。
3. 一覧の右上の「保存」ボタンを押します。

### 選手を削除する

1. 一覧の選手の行の「削除」ボタンを押すと、一覧から消えます。
2. 一覧の右上の「保存」ボタンを押すと、削除が確定します（保存する前なら、別の大会や画面に移ると元に戻ります）。
   - スコアが保存されている選手は削除できません（「削除」ボタンが押せません）。

### 当日来られない選手（不参加）

登録した選手が参加しないときは、選手を削除せずに「不参加」にできます。

1. 一覧の選手の行の「不参加」ボタンを押します。行が灰色になり、名前の横に「不参加」と表示されます。
2. 一覧の右上の「保存」ボタンを押します。
3. 不参加の選手は、組合せ表に入らず、順位表にも出ません（選手の情報は残ります）。
4. 参加に戻すときは「参加に戻す」ボタンを押して、「保存」を押します。

### 一覧の並べ替え

一覧の見出しの「選手名」「生年月日」「チーム名」「パーティ固定」をクリックすると並べ替えられます。クリックするたびに、小さい順（▲）→ 大きい順（▼）→ 登録した順 と切り替わります。並べ替えは見え方だけで、登録した内容は変わりません。

### 注意

- 組合せ表を作成した後で（スコアがまだ1件も保存されていないとき）、選手の追加・削除、または「選手名」「生年月日」「チーム名」「パーティ固定」「パーティ番号」「不参加」のどれかを変更して「保存」を押すと、「組合せ表・スコア表の削除確認」の画面が出ます。「変更する」を押すと組合せ表・スコア表が削除されて保存されます。組合せ表をもう一度作成してください（5章）。選手名・生年月日だけの変更でも、この画面が出ます。
- **スコアが1件でも保存されると**、全選手の「チーム名」「パーティ固定」「パーティ番号」「参加／不参加」は変更できなくなり、スコアのある選手は削除できなくなります（選手名・生年月日の修正はできます。このときは確認の画面は出ず、組合せ表・スコアもそのまま残ります）。一覧の下に「※試合結果が登録されているため、パーティ固定・パーティ番号・チーム名・参加／不参加の変更、および試合結果のある選手の削除はできません。」と表示されます。
- 大会が「終了」のときは変更できません。

## 5. 組合せ表の作成

競技情報と選手を登録したら、組合せ表（パーティ分けと開始ホール）を作成します。

### 組合せ表を作成する

1. 大会の画面（「大会情報」「競技情報」「選手情報」のどのタブでもかまいません）で、「組合せ表を作成する」ボタンを押します。
2. 「組合せ表を作成しますか？」と表示されます。「作成する」を押します。
3. 「組合せ表を作成しました」と表示されれば完了です。
4. 「大会を開催する」ボタンを押すと、「組合せ・スコア表」の画面が開き、作成した組合せ表を確認できます。
   - 「大会を開催する」ボタンは、組合せ表を作成するまでは押せません。

### 組合せ表の作られ方

- 対象は「不参加」以外の全選手です。参加する選手が2人以上必要です。
- 「パーティ固定」の選手は、指定したパーティ番号のパーティに入ります。
- それ以外の選手は、競技情報の「パーティの決定方法」（チーム／シャッフル）に従って自動で分けられます。「シャッフル」の場合は作成するたびに組合せが変わります。
- 各パーティの開始ホール（1〜8）も自動で決まります。パーティ番号の順に、なるべく同じ数ずつ、1番ホールから順に割り当てられます。
  - 例：20パーティの場合、1番〜6番ホールに3パーティずつ、7番ホールに2パーティが割り当てられます。

### 作成できないとき（「エラー」の画面）

| 表示されるメッセージ | 直し方 |
|---|---|
| 競技情報が登録されていません。競技情報を登録してください。 | 「競技情報」タブで競技情報を保存してください（3章） |
| 参加選手数が2名未満のため組合せ表を作成できません。選手を2名以上登録してください。 | 選手を2人以上登録してください。「不参加」の選手は数えません |
| パーティ番号○○の人数がパーティの最大人数を超えています。選手情報のパーティ番号を見直してください。 | 同じパーティ番号に固定した選手が多すぎます。選手のパーティ番号を見直してください |
| チーム『○○』の人数がパーティの最大人数を超えています。選手情報またはパーティの最大人数を見直してください。 | 「チーム」で分ける場合、1チームの人数はパーティの最大人数以下にする必要があります。チームを分けるか、パーティの最大人数を増やしてください |
| チーム名が未入力の選手がいます。選手情報を見直してください。 | 「チーム」で分ける場合は、全選手にチーム名が必要です |
| 試合結果が入力されています。試合結果を削除して下さい。 | スコアを入力した後は作り直せません。下の「組合せ表を作り直したいとき」を参照してください |

### 組合せ・スコア表の画面の見かた

「組合せ・スコア表」の画面では、パーティごとに次の内容が1つの表にまとめて表示されます。

| 列 | 内容 |
|---|---|
| パーティ番号 | パーティの番号 |
| 開始グループ | 同じ開始ホールから出るパーティの順番（1, 2, 3…）。パーティ番号の小さい順につきます。その開始ホールを使うのが1パーティだけなら「1」です |
| 開始ホール | 最初に打ち始めるホールと、変更するための「変更」ボタン |
| 選手名・チーム名・生年月日 | 選手の情報（チーム名がない場合は「-」） |
| 年齢 | 大会の開催日の時点の年齢（例：「55歳176日」＝55歳と176日） |
| ラウンド | R1（1ラウンド目）、R2（2ラウンド目）… |
| ホール（1〜8） | 各ホールの打数。まだ入力していないところは「ー」。ホールの並びは、開始ホールに関係なく、いつも1番から8番の順です |
| 小計 | そのラウンドの合計 |
| 合計 | その選手の、入力済みのラウンドの合計 |
| スコア入力 | 「ラウンド1：未入力」「ラウンド1：入力済」などのボタン（6章） |

- 画面上部の「組合せ・スコア表」「順位表」のタブで、順位表の画面と行き来できます。
- 「← 大会情報」で大会の画面に、「← 大会一覧」で大会一覧に戻ります。
- まだ組合せ表を作成していないときは「まだ組合せ表が作成されていません。」と表示されます。「大会情報画面へ戻る」から大会の画面に戻り、組合せ表を作成してください。

### 開始ホールを変更する

自動で決まった開始ホールは、パーティごとに変更できます。

1. 変更したいパーティの「開始ホール」の下にある「変更」ボタンを押します。
2. 「パーティ○ の開始ホール変更」の画面で、1〜8 から開始ホールを選び、「保存」を押します。
   - 同じ開始グループ（変更前）のほかのパーティがすでに使っている開始ホールは選べません。選択肢に「（同じ開始グループのパーティ○が使用中）」と表示されます。同じ時間に同じホールから2つのパーティが出発しないようにするためです。
   - 開始ホールを変更すると、開始グループの番号は自動でつけ直されます。
   - 開始ホールの変更は、スコアを入力した後でもできます（大会が「終了」のときはできません）。

### パーティの並べ替え

表の見出しの「パーティ番号」「開始グループ」「開始ホール」をクリックすると、パーティの並び順を変えられます。クリックするたびに、小さい順（▲）→ 大きい順（▼）→ もとの順（パーティ番号順）と切り替わります。

- 例：「開始グループ」で並べると、最初に出発するパーティ（開始グループ1）がまとめて上に並びます。
- 並べ替えは見え方だけで、組合せ表の内容は変わりません。

### 組合せ表を作り直したいとき

- **スコアをまだ入力していない場合**：大会の画面で「組合せ表を作成する」をもう一度押します。「組合せ表は作成済みです。再作成すると現在のパーティ編成・開始ホール・スコア表は上書きされます。」と表示されるので、よければ「作成する」を押します。手で変更した開始ホールも作り直されます。
- **スコアを入力した後の場合**：そのままでは作り直せません。どうしても作り直す場合は、入力したスコアをすべて削除してから（6章「スコアを削除する」）作り直してください。

## 6. スコアの入力

### スコアを入力する

1. 大会の画面で「大会を開催する」ボタンを押し、「組合せ・スコア表」の画面を開きます。
2. 入力したいパーティの「スコア入力」の列にある、ラウンドのボタン（例：「ラウンド1：未入力」）を押します。
3. 「パーティ○ ラウンド○ スコア入力」の画面が開きます。パーティの全選手について、1番〜8番ホールの打数（1〜99）を入力します。
   - 入力欄には、はじめは「1」が入っています。スコアカードを見ながら、8ホールすべて書き換えてください。
   - 入力欄の並びは、開始ホールに関係なく、いつも1番から8番の順です。スコアカードの順番と違うことがあるので、ホール番号をよく確かめてください。
   - ホールインワンのホールは「1」と入力します（変換はアプリが自動で行います）。
4. 「保存」ボタンを押します。
   - **8ホール分・パーティ全員分をまとめて保存します。** 一部のホールだけを保存することはできません。
   - 打数が空欄や範囲外のときは「打数は1〜99の整数で入力してください」と表示され、保存されません。
5. 保存すると画面が閉じ、表のそのラウンドの行に打数・小計・合計が表示されます。ボタンは「ラウンド1：入力済」に変わります。
6. ほかのパーティ・ラウンドも同じように入力します。

### ホールインワンの表示と計算

- 競技情報で「変換あり」の場合、打数1のホールは「1(-2)」のように、かっこの中に変換後の点数が表示されます（変換値が1のときはかっこは付きません）。
- 小計・合計は、かっこの中の点数（変換後）で計算されます。
- 例：変換値が-2のとき、8ホールの打数が「1, 3, 4, 3, 3, 4, 3, 3」なら、小計は -2＋3＋4＋3＋3＋4＋3＋3 ＝ 21 です。

### 入力したスコアを修正する

1. 修正したいパーティの「ラウンド○：入力済」ボタンを押します。
2. 保存されている打数が表示されるので、書き換えて「保存」を押します。

### スコアを削除する

1. 削除したいパーティの「ラウンド○：入力済」ボタンを押します。
2. 画面左下の「このラウンドのスコアを削除」ボタンを押します。
3. 「スコアの削除」の画面で「このパーティのこのラウンドのスコアを削除し、未入力に戻します。削除しますか？」と表示されます。よければ「削除する」を押します。
4. そのパーティ・ラウンドのスコアが「未入力」に戻ります。

### 注意

- **スコアを保存しても、順位表は自動では変わりません。** 順位を見るときや、スコアを修正した後は、順位表の画面で「順位表作成」ボタンを押してください（7章）。
- 大会が「終了」のとき、閲覧モードのときは、スコアの入力・修正・削除はできません（表の上に赤い文字で理由が表示されます）。

## 7. 順位表の確認

### 順位表を作成する

1. 「組合せ・スコア表」の画面上部の「順位表」タブを押します。
2. 「順位表作成」ボタンを押します。
3. その時点で保存されているスコアをもとに順位が計算され、表示されます。画面左上に「作成日時：」として作成した日時が表示されます。
   - スコアを入力・修正したら、そのたびに「順位表作成」を押し直してください。押し直さない限り、順位表は前に作成したときのままです。

### 順位表の見かた

**個人戦 総合順位表**（いつも表示されます）

- 「順位」「選手名」「チーム名」「総合スコア」「年齢」が表示されます。
- 順位の決め方：
  1. 総合スコア（全ラウンドの合計）が少ない人が上
  2. 同じスコアなら、年齢が上（生年月日が早い）の人が上
  3. それでも同じなら、じゃんけん

**チーム戦 総合順位表（合計／平均）**（競技情報で「チーム戦あり」のときだけ表示されます）

- 「順位」「チーム名」「人数」「合計スコア」（平均の場合は「平均スコア」。小数第2位まで表示）「合計年齢」が表示されます。
- 順位の決め方：
  1. チームの合計（または平均）スコアが少ないチームが上
  2. 同じなら、チームの選手の年齢を合計した「合計年齢」が上のチームが上
  3. それでも同じなら、じゃんけん
- 「合計年齢」は、各選手の「◯歳◯日」の「歳」と「日」をそれぞれ足した表示です（日が365日を超えても「歳」には繰り上げません）。

**集計の対象にならない選手**

- 全ラウンドのスコアが保存されていない選手は、順位表に入りません。表の下に「全ラウンド分のスコアが保存されていないため集計対象外：（選手名）」と表示されます。入力もれがないか確かめてください。
- 「不参加」の選手は、順位表にも、集計対象外の一覧にも表示されません。
- チーム戦では、集計対象外の選手はチームの合計・平均・合計年齢にも入りません。

### 同じ順位の人がいるとき（じゃんけん・手動確定）

スコアも年齢も同じで順位が決まらないときは、同じ順位で表示され、その行に「じゃんけん待ち」と「手動確定」ボタンが表示されます。

1. 該当する選手（またはチーム）に、会場でじゃんけんをしてもらい、順位を決めます。
2. 1人目（1チーム目）の行の「手動確定」ボタンを押します。
3. 「○○ の最終順位を手動確定」の画面で、「確定する順位（n〜m）」に、じゃんけんで決まった順位を入力します。入力できるのは、その同順位のグループの範囲（例：2〜3）だけです。
4. 「確定する」を押します。その行の「じゃんけん待ち」が消え、順位が書き換わります。
5. 同じグループのほかの選手（チーム）についても、同じように「手動確定」を行います。最後の1人も「手動確定」が必要です。
   - 同じグループで、すでに確定した順位は入力できません（「○位は同じグループ内で既に確定済みです」と表示されます）。

**注意**：「順位表作成」をもう一度押すと、順位表はスコアから計算し直され、**手動確定した順位は消えて**、再び「じゃんけん待ち」に戻ります。じゃんけんの結果の入力は、すべてのスコアを入力し、最後の「順位表作成」を行った後にしてください。

## 8. 大会の終了と取り消し

大会が終わったら、間違ってデータを変えてしまわないように、大会を「終了」にします。

### 大会を終了する

1. 大会の画面（「大会情報」「競技情報」「選手情報」のいずれか）で「大会を終了する」ボタンを押します。
2. 「大会を終了しますか？」の画面で「大会を終了すると、大会情報・競技情報・選手情報の編集、スコアの入力・修正、順位表の作成、順位の手動確定（じゃんけん結果の確定）ができなくなります。終了しますか？」と表示されます。よければ「終了する」を押します。
3. 大会名の横の表示が「終了」に変わります。

### 「終了」の間にできないこと

- 大会情報・競技情報・選手情報の変更（入力欄と「保存」「キャンセル」ボタンが灰色で押せなくなり、「大会が終了しているため変更できません」と表示されます）
- 組合せ表の作成（「組合せ表を作成する」「大会を開催する」ボタンが灰色で押せなくなります）
- 開始ホールの変更、スコアの入力・修正・削除
- 順位表の作成（「順位表作成」ボタンが灰色で押せなくなります）
- 順位表の手動確定（じゃんけんの結果の入力。「手動確定」ボタンが灰色で押せなくなります）

順位表は「終了」の前に作成しておいてください。じゃんけんの結果の入力も、「終了」の前に済ませてください（「終了」の後で必要になったときは、「大会を再開する」で一度「進行中」に戻してから行います）。

「終了」の間も、組合せ・スコア表と順位表（「終了」の前に作成したもの）を見ることはできます。大会の画面の「大会を閲覧する」ボタンを押すと、組合せ・スコア表の画面が開きます。大会の削除もできます。

### 終了を取り消す（大会を再開する）

入力の誤りに気づいたときなどは、「終了」を取り消して、元の「進行中」に戻せます。

1. 大会の画面で「大会を再開する」ボタンを押します。
2. 「大会を再開しますか？」の画面で「再開する」を押します。
3. 「進行中」に戻り、再び変更できるようになります。修正が終わったら、もう一度「大会を終了する」を行ってください。

## 9. 参加者に結果を見せる

参加者がそれぞれのスマートフォンなどから結果を見る仕組み（参加者向けの閲覧ページ）は、今後の対応予定で、現在のアプリにはありません。

会場で参加者に組合せ表や順位表を見せる場合は、このパソコンの画面を見せてください。データを誤って変えないように、次のように「閲覧モード」で表示すると安心です。

1. 画面右上の「ログアウト」を押してログアウトします（11章）。
2. ログイン画面で「閲覧モードで見る（ID・パスワード不要）」を押します。
3. 大会一覧から大会を選び、「大会を閲覧する」ボタンで組合せ・スコア表を、「順位表」タブで順位表を表示します。
   - 閲覧モードでは「順位表作成」を押せません。最新の順位を見せたいときは、管理者でログインしている間に「順位表作成」を押しておいてください。

## 10. バックアップと復元

バックアップは、その時点のすべての大会のデータ（大会情報・競技情報・選手情報・組合せ表・スコア表・順位表）を、パソコンの中に保存しておく機能です。間違って削除したときや、データがおかしくなったときに、バックアップした時点に戻せます（復元）。

画面右上の「バックアップ」ボタンを押すと、「バックアップ・リストア」の画面が開きます。「← 大会一覧」で大会一覧に戻ります。

### 手動でバックアップする

1. 「手動バックアップ」ボタンを押します。
2. 「バックアップを作成しました」と表示され、下の履歴に追加されます。
   - 大事な操作（組合せ表の作り直し、復元など）の前や、スコアの入力がひと区切りしたときに、こまめにバックアップしておくと安心です。

### バックアップ履歴

- 履歴には、作成した日時（例：2026/11/16 15:00:00）と、作成のきっかけ（「手動」＝手動バックアップ、「ログアウト」＝ログアウトのときのバックアップ）が、新しい順に表示されます。
- 履歴は**最大20件**まで残ります。21件目を作成すると、いちばん古いものから自動で削除されます。
- 「開始日」「終了日」を選んで「絞込」を押すと、その期間に作成した履歴だけを表示できます（どちらか一方だけでもかまいません）。

### 復元する（バックアップした時点に戻す）

1. 履歴の中から、戻したい日時の左の丸（ラジオボタン）をクリックして選びます。
2. 右下の「復元」ボタンを押します。
3. 「復元の最終確認」の画面で「現在のすべてのデータが、選択したバックアップ（作成日時）の内容で完全に上書きされます。元に戻せません。復元しますか？」と表示されます。日時をよく確かめて、よければ「復元する」を押します。
4. 「復元しました」と表示されれば完了です。

**注意**

- 復元すると、**すべての大会**のデータが、選んだバックアップの時点の内容に置き換わります。その後に入力したスコアなどは消えます。迷ったときは、復元の前に「手動バックアップ」で今の状態を保存しておいてください（今の状態にも戻せるようになります）。
- バックアップ履歴そのものは復元しても消えません。
- ログインID・パスワードはバックアップ・復元の対象ではありません（復元してもID・パスワードは変わりません）。
- 閲覧モードでは、バックアップ・復元はできません。

## 11. ログアウト

1. 画面右上の「ログアウト」ボタンを押します。
2. 「ログアウトしますか？」と表示されます。ログアウトする場合は「ログアウトする」、やめる場合は「しない」を押します。
3. 「ログアウトする」を押すと、続けて「バックアップを作成しますか？」と表示されます。
   - 「バックアップする」：バックアップを作成してからログアウトします（履歴のきっかけは「ログアウト」になります）。**ふだんはこちらをおすすめします。**
   - 「しない」：バックアップを作成せずにログアウトします。
4. ログイン画面に戻ります。

閲覧モードのときは「バックアップする」は押せません（「しない」を押してください）。

## ID・パスワードを忘れた場合

ログインID・パスワードを忘れてしまった場合は、次の手順で、ID・パスワードを**インストール時の初期の値**（「インストール手順書」の「4. 初回起動」に書かれているもの）に戻せます。

**大会のデータ・バックアップは消えません。** 戻るのはID・パスワードだけです。

### しくみ

アプリのデータは、パソコンの次のフォルダ（データ保存先）に保存されています。

| パソコン | データ保存先のフォルダ |
|---|---|
| Windows | `%ProgramData%\グランドゴルフしようよ`（通常は `C:\ProgramData\グランドゴルフしようよ`） |
| Mac | `/Library/Application Support/グランドゴルフしようよ` |

このフォルダの中の `admin.json` というファイルに、ログインID・パスワードが（暗号化して）保存されています。このファイルを削除すると、次にログインするときに、初期のID・パスワードで自動的に作り直されます。

フォルダには、ほかに次のファイルがあります。**これらは削除しないでください。**

| ファイル・フォルダ | 内容 |
|---|---|
| `db.json` | すべての大会のデータ |
| `backups` | バックアップ |
| `logs` | 動作の記録（不具合調査用） |
| `session-secret.json` | ログイン状態を守るための鍵 |

### 手順（Windows）

1. アプリを終了します（ウィンドウの「×」を押します）。
2. キーボードの **Windowsキー** を押しながら **R** キーを押すと、「ファイル名を指定して実行」が開きます。
3. `%ProgramData%\グランドゴルフしようよ` と入力し、「OK」を押します。データ保存先のフォルダが開きます。
4. `admin.json`（「.json」が表示されていない場合は `admin`）を右クリックし、「削除」を選びます。
   - **`db.json`（`db`）や `backups` フォルダは削除しないでください。**
5. アプリを起動し、「インストール手順書」に書かれた初期のID・パスワードでログインします。
6. ログイン画面の「ログイン情報を変更する」から、新しいID・パスワードに変更します（1章）。

### 手順（Mac）

1. アプリを終了します（メニューバーの「グランドゴルフしようよ」→「終了」、または **command** キーを押しながら **Q** キー）。
2. Finderを開き、メニューバーの「移動」→「フォルダへ移動...」を選びます。
3. `/Library/Application Support/グランドゴルフしようよ` と入力し、**return** キーを押します。データ保存先のフォルダが開きます。
4. `admin.json` をゴミ箱にドラッグします。Macのパスワードを求められた場合は、Macの管理者のパスワードを入力します。
   - **`db.json` や `backups` フォルダはゴミ箱に入れないでください。**
   - Finderで削除できない場合は、管理者権限のあるMacアカウントで「ターミナル」を開き、次のコマンドを入力して **return** キーを押し、Macのパスワードを入力します。

     ```
     sudo rm "/Library/Application Support/グランドゴルフしようよ/admin.json"
     ```

5. アプリを起動し、「インストール手順書」に書かれた初期のID・パスワードでログインします。
6. ログイン画面の「ログイン情報を変更する」から、新しいID・パスワードに変更します（1章）。

自分で操作するのが不安な場合は、導入時の担当者に相談してください。

## 困ったとき

| こんなとき | どうする |
|---|---|
| ボタンが灰色で押せない | 次のどれかに当てはまっていないか確かめてください。①閲覧モードになっている（画面上部に「閲覧モード」と表示）→ ログアウトして、ID・パスワードでログインし直す。②大会が「終了」になっている → 「大会を再開する」（8章）。③スコアが保存されている → 競技情報や、選手のチーム名・パーティなどは変更できません（3章・4章）。「順位表作成」「手動確定」が押せないときは①か②です |
| 「大会を開催する」ボタンが押せない | まだ組合せ表を作成していません。「組合せ表を作成する」を押してください（5章） |
| 組合せ表が作成できない | 「エラー」の画面のメッセージを読み、5章「作成できないとき」の表を参照してください |
| 選手を登録したのに、ほかの画面に移ったら消えた | 一覧の右上の「保存」ボタンを押していなかった可能性があります。もう一度登録し、最後に「保存」を押してください（4章） |
| 生年月日が入力できない | 半角で `1971/5/24` または `S46.5.24` の形で入力してください（4章） |
| スコアを入力したのに順位表が変わらない | 順位表の画面で「順位表作成」を押してください（7章） |
| 順位表に出ない選手がいる | 全ラウンドのスコアが保存されているか確認してください。表の下の「集計対象外」に名前が出ていれば、入力もれがあります（7章） |
| じゃんけんで決めた順位が元に戻った | 「順位表作成」を押し直すと、手動確定した順位は消えます。もう一度「手動確定」を行ってください（7章） |
| 間違ってデータを消してしまった | 「バックアップ」から、消す前のバックアップを選んで復元してください（10章） |
| ID・パスワードを忘れた | 「ID・パスワードを忘れた場合」を参照してください |
| 画面が動かない・表示がおかしい | アプリをいったん終了して、もう一度起動してください |
| 「〜を起動できません」と表示されてアプリが起動しない | 「インストール手順書」の「8. うまくいかないとき」を参照してください |
| それでも解決しない | 導入時の担当者にお問い合わせください。その際、データ保存先フォルダの中の `logs` フォルダにある `server.log` を求められることがあります |
