# 用語集

## 目的

本ドキュメントは、`要件定義書.md`・`画面仕様書.md`・画面（`src/app`・`src/components`）に現れる用語と、開発者向けの技術用語を整理し、文書・画面・コードの間で用語の表記や意味がぶれないようにするためのものです。

- 定義の一次情報源は `要件定義書.md` です。本ドキュメントと齟齬がある場合は要件定義書を優先してください。
- 「要件定義書」列は、その用語を定義・規定している要件定義書の節を示します（「―」は要件定義書に記載がなく、画面仕様書または実装で定まっている用語）。
- 「実装上の名前」列は、`src/types/tournament.ts` 等での型・フィールド名です。
- 新しい用語を追加・変更した場合は、本ドキュメントも合わせて更新してください。

## 表記ゆれ・曖昧語への注意

- **「試合結果」と「スコア」**：要件定義書では「試合結果」と「スコア」がほぼ同じ対象（保存済みの打数）を指す。画面では主に「スコア」、ブロック系の注記では「試合結果が登録されているため…」と表記している。
- **「総合スコア」と「トータルスコア」と「合計」**：要件定義書・A7の列名は「総合スコア」、A7の順位決定方法の注記は「トータルスコア」、A6の列名は「合計」（入力済みラウンドのみの合計）と表記が分かれている。A6の「合計」は全ラウンド未入力でも途中経過を表示する点で、A7の「総合スコア」と意味が異なる。
- **「生年月日が早い」と「年齢が上」**：個人戦の第2基準。要件定義書は「生年月日(年上が上位)」、画面の注記は「年齢が上」と表記するが、いずれも生年月日の早い方を上位とする同じ基準。
- **「パーティ番号」**：選手情報のパーティ番号（固定先の指定）と、組合せ表のパーティ番号（生成されたパーティの番号）がある。固定選手のパーティでは両者は一致する。
- **「ログイン情報の変更」と「ID・パスワード変更」**：画面の表記は「ログイン情報を変更する」（ダイアログ見出し「ログイン情報の変更」）。インストール手順書・操作手順書の説明文では「ID・パスワードを変更する」とも表記するが、同じ操作を指す。
- **「リストア」と「復元」**：同じ操作を指す。画面名は「バックアップ・リストア」、ボタン・ダイアログは「復元」「復元の最終確認」「復元する」。
