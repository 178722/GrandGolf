# 画面仕様書

## 目的

本ドキュメントは `要件定義書.md` の機能要件を実現するための画面構成・画面遷移・各画面の表示項目/操作を定義する。

- 定義の一次情報源は `要件定義書.md` です。本ドキュメントと齟齬がある場合は要件定義書を優先してください。
- 本書は画面一覧・表形式の仕様・簡易テキストワイヤーフレームの粒度で記述し、詳細なビジュアルデザイン（配色・フォント等）は対象外とする。
- グランドゴルフはBaseProject（リーグ戦しようよ）と異なり、カテゴリ・コート・審判の概念を持たない（要件定義書1〜3章参照）。そのため画面構成もカテゴリタブ・コートタブを持たず、よりシンプルな構成とする。

## 利用者とURL構成

| 利用者 | 認証 | URLプレフィックス | 対応するディレクトリ |
|---|---|---|---|
| 管理者 | ログイン必須（単一アカウント） | `/tournaments`・`/settings`（ログイン後） | `src/app/tournaments/`・`src/app/settings/` |
| 閲覧モード利用者 | ログイン画面の「閲覧モードで見る」で読み取り専用セッションを発行（ID・パスワード不要） | 管理者と同じ | 管理者と同じ（画面を共用し、書き込み操作のみ不可） |

- ログイン画面は `/login`（`src/app/login/`）。`/` にアクセスした場合は `/login` へリダイレクトする。
- 以下の画面一覧の「利用者」欄は管理者と記載しているが、閲覧モード利用者もA1以外の全画面を同じ範囲で閲覧できる（`要件定義書.md` 2.3参照）。

参加者向けのログイン不要URL（`/t/:tournamentId`）は将来対応のため今回のスコープには含まない（`要件定義書.md` 5章参照）。

## 共通仕様

### 共通ヘッダー（管理者画面）

全管理者画面（A2〜A8）はヘッダーとナビゲーションを共有する。

```
+----------------------------------------------------------------+
| グランドゴルフしようよ [閲覧モード]           [バックアップ] [ログアウト] |
+----------------------------------------------------------------+
```

- タイトル「グランドゴルフしようよ」はA2（大会一覧）へのリンク。「[閲覧モード]」バッジは閲覧モードの場合のみ表示する。
- 「バックアップ」ボタンはA8へ遷移する（閲覧モードでも遷移可。A8内の書き込み操作はdisabled）。

大会単位の画面のうち、A3・A4・A5は、大会名ヘッダー（1行目：大会名・ステータスバッジ、2行目：開催日・開催場所）を共通で表示し、これに続けて共通タブ（[大会情報][競技情報][選手情報]）で画面を切り替える。A6・A7も同じ大会名ヘッダーの下に、共通タブとは別の「大会運営タブ」（[組合せ・スコア表][順位表]）を表示する（A6・A7には共通タブを表示せず、代わりに「← 大会一覧」「← 大会情報」の2つの戻るリンクを表示する）。A8は共通タブを持たず、大会一覧へ戻るリンクのみを表示する。

```
+----------------------------------------------------------------+
| ← 大会一覧                                                        |
| 定例会 [進行中]                                                   |
| 2026/11/16・グラウンド                                            |
+----------------------------------------------------------------+
| [ 組合せ表を作成する ] [ 大会を開催する ] [ 大会を終了する ]         |   ← A3・A4・A5共通表示
+----------------------------------------------------------------+
| [大会情報] [競技情報] [選手情報]                                    |   ← A3・A4・A5
+----------------------------------------------------------------+
```

```
+----------------------------------------------------------------+
| ← 大会一覧  ← 大会情報                                             |
| 定例会 [進行中]                                                   |
| 2026/11/16・グラウンド                                            |
+----------------------------------------------------------------+
| [組合せ・スコア表] [順位表]                                         |   ← A6・A7（大会運営タブ）
+----------------------------------------------------------------+
```

大会運営タブ（[組合せ・スコア表][順位表]）への入口は、A3・A4・A5共通のボタン群の「大会を開催する」ボタン（組合せ表が1件でも生成済みであれば活性）と「大会を閲覧する」ボタン（大会ステータス＝終了、または閲覧モードの場合）の2つのみとする。組合せ表の生成・再生成は同じボタン群の「組合せ表を作成する」ボタンからのみ行い、A6自身には生成・再生成ボタンを設けない。

### 認証・セッション

- A1でのログイン成功時にサーバー側でセッションを発行し、Cookieで保持する。以降、管理者向け画面（A2〜A8）およびそのAPIは、このセッションが有効な場合のみアクセスできる。
- セッションが無効な状態で管理者向け画面にアクセスした場合は、A1（ログイン画面）へ自動的にリダイレクトする。

### ログアウト確認

共通ヘッダーの「ログアウト」ボタンをクリックすると、以下の2段階の確認を経てログアウトを実行する（要件定義書4章参照）。

1. 「ログアウトしますか？」（しない／ログアウトする）を表示する。
2. 1で「ログアウトする」を選んだ場合のみ、続けて「バックアップを作成しますか？」（しない／バックアップする）を表示し、選択に従ってバックアップ作成の有無を決定したうえでログアウトを実行し、[A1 ログイン画面]へ遷移する。

閲覧モードの場合、2の「バックアップする」ボタンはdisabledとし（「しない」のみ選択可）、APIでもバックアップは作成しない。

### 共通バリデーション表示

- `要件定義書.md` 3章冒頭の規定に従い、MAX文字数超過・範囲外の数値はエラーメッセージを表示して保存を拒否する（自動切り詰めは行わない）。文字数は全角・半角を区別せず1文字として数える。
- 入力欄ごとのエラーは該当入力欄の直下に赤字で表示する（例：「大会名は50文字以内で入力してください」「選手名「○○」は既に登録されています」）。
- サーバー側で検出したエラー（ブロック系ルール・組合せ表生成エラー等）は、画面上部の保存ボタン横の赤字メッセージ、ダイアログ内の赤字メッセージ、または「エラー」ダイアログ（「閉じる」ボタンのみ）で表示する。

### 共通確認ダイアログ

確認ダイアログは「キャンセル（またはしない）」と実行ボタンの2ボタン構成とする。

| 操作 | ダイアログ見出し | 文言 | ボタン |
|---|---|---|---|
| 大会の削除（A2のみ） | 大会を削除しますか？ | 「この大会（大会名）を削除すると、紐づく競技情報・選手情報・組合せ表・スコア表・順位表がすべて削除されます。元に戻せません。削除しますか？」 | キャンセル／削除する |
| 組合せ表の作成（A3〜A5「組合せ表を作成する」ボタン） | 組合せ表を作成しますか？ | 未生成の場合「登録済みの全選手を対象に、パーティ編成と開始ホールを自動で作成します。」、生成済みの場合は赤字で「組合せ表は作成済みです。再作成すると現在のパーティ編成・開始ホール・スコア表は上書きされます。」 | キャンセル／作成する |
| 大会の終了（A3〜A5「大会を終了する」ボタン） | 大会を終了しますか？ | 「大会を終了すると、大会情報・競技情報・選手情報の編集、スコアの入力・修正、順位表の作成、順位の手動確定（じゃんけん結果の確定）ができなくなります。終了しますか？」 | しない／終了する |
| 大会の再開（A3〜A5「大会を再開する」ボタン） | 大会を再開しますか？ | （本文なし） | しない／再開する |
| 競技情報・選手情報の変更（組合せ表生成後・試合結果未入力） | 組合せ表・スコア表の削除確認 | 「既存の組合せ表・スコア表を削除し、再生成が必要になります。変更しますか？」 | キャンセル／変更する |
| スコアの削除（A6スコア入力ダイアログ） | スコアの削除 | 「このパーティのこのラウンドのスコアを削除し、未入力に戻します。削除しますか？」 | キャンセル／削除する |
| バックアップからの復元（リストア） | 復元の最終確認 | 「現在のすべてのデータが、選択したバックアップ（作成日時）の内容で完全に上書きされます。元に戻せません。復元しますか？」 | キャンセル／復元する |

### 共通エラー・制限表示（ブロック系ルール）

登録済みデータの存在や大会ステータスによって編集・削除がブロックされる場合（要件定義書2.1, 3.2, 3.3参照）、対象のボタン・入力欄をdisabledにし、理由をツールチップまたは注記で表示する。APIでも同じ条件で拒否する。

例：「試合結果が登録されているため変更できません」「大会が終了しているため変更できません」「閲覧モードのため変更できません」

閲覧モード（要件定義書2.3）でログインしている場合も同様に、登録・編集・削除・生成・スコア入力・バックアップ作成・リストアなど書き込みを伴う操作は行えない（APIでも拒否する）。共通ヘッダーには「閲覧モード」であることを示すバッジを表示する。

画面ごとの読み取り専用時（大会終了・閲覧モード）の表示は以下のとおり。書き換え系の操作ボタンは非表示にせず、表示したままdisabledにする（要件定義書2.1・2.3「該当する操作のボタンはUI上disabledにする」）。

| 画面 | 読み取り専用時の表示 |
|---|---|
| A2 | 「+ 新規作成」「削除」ボタンをdisabled（閲覧モードのみ。大会の削除はステータスに関わらず可能）。閲覧モードで `/tournaments/new` に直接アクセスした場合はA2へ戻す |
| A3・A4 | 入力欄をdisabled（読み取り専用）にし、「保存」「キャンセル」（A4は「保存」のみ）ボタンは非表示にせず表示したままdisabledにし、フォーム下部に理由を赤字で注記する（A4で試合結果が登録済みの場合も同様） |
| A3〜A5のボタン群 | 「ステータス別のボタン構成」（A3参照）のとおり。閲覧モード・大会終了中も「組合せ表を作成する」「大会を開催する」は非表示にせず、表示したままdisabledにする |
| A5 | 「+ 新規登録」「保存」と行内の「編集」「不参加／参加に戻す」「削除」ボタンをdisabledにし、一覧下部に理由を赤字で注記する |
| A6 | 開始ホールの「変更」ボタン・スコア入力ボタンをdisabledにし、表の上部に理由を赤字で注記する |
| A7 | 「順位表作成」「手動確定」ボタンをdisabledにし、ボタンの下に理由を赤字で注記する（閲覧モード・大会終了中とも。作成済みの順位表は閲覧できる） |
| A8 | 閲覧モードのみ「手動バックアップ」「復元」ボタンをdisabled |

## A1. ログイン画面

### 概要
環境変数でシードされた単一の管理者アカウントでログインする。ID・パスワードなしで管理者向け画面を読み取り専用で利用できる「閲覧モード」ボタンも用意する（要件定義書2.3参照）。

### 表示・入力項目

| 項目 | 種別 | 必須 | 備考 |
|---|---|---|---|
| ID | テキスト入力 | ◯ | |
| パスワード | パスワード入力（マスク） | ◯ | 最低8文字 |

### 操作

| 操作 | 内容 |
|---|---|
| ログインボタン | 認証成功時は[A2 大会一覧画面]へ遷移。失敗時はエラーメッセージを表示 |
| 閲覧モードで見るボタン | ID・パスワードの入力なしで読み取り専用セッションを発行し[A2 大会一覧画面]へ遷移する |
| ログイン情報を変更するボタン | 「ログイン情報の変更」ダイアログを開く。入力欄は「現在のID」「現在のパスワード」（本人確認）、「新しいID」「新しいパスワード（最低8文字）」で、すべて必須。「変更する」で変更し、成功時は「ログイン情報を変更しました。」を表示する（「閉じる」で閉じる）。現在のID・パスワードが誤っている場合は「現在のID・パスワードが正しくありません」を表示する |

ログイン失敗時のエラーメッセージは「IDまたはパスワードが正しくありません」とする。

### 遷移先
- ログイン成功 → A2
- 閲覧モードで見る → A2（閲覧モード）

## A2. 大会一覧画面

### 概要
ログイン後のホーム画面。登録済みの大会を一覧表示し、新規作成・遷移・削除を行う（要件定義書3.1）。

### 表示項目

| 項目 | 内容 |
|---|---|
| 大会名 | 一覧の各行 |
| 開催日 | 一覧の各行 |
| 開催場所 | 一覧の各行 |
| ステータス | 「進行中」または「終了」のバッジ表示 |

- 並び順は開催日の新しい順（同じ開催日の場合は登録の新しい順）。
- 大会が1件もない場合は「登録されている大会はありません。「+ 新規作成」から登録してください。」を表示する。

### 操作

| 操作 | 内容 |
|---|---|
| 「+ 新規作成」ボタン | [A3 大会情報画面（新規）]へ遷移。閲覧モードではdisabled |
| 行クリック | [A3 大会情報画面]へ遷移する |
| 削除ボタン（行内） | 確認ダイアログ表示後、カスケード削除を実行（大会のステータスに関わらず削除可能）。閲覧モードではdisabled |

### 遷移先
- 新規作成 → A3（新規）
- 行選択 → A3

### ワイヤーフレーム

### 概要

## A5. 選手情報画面

### 概要
大会全体の選手の一覧表示・登録・編集・削除を行う（要件定義書3.3）。

### 一覧表示項目

| 項目 | 内容 |
|---|---|
| 選手名 | 不参加の選手は名前の横に「不参加」ラベルを表示し、行をグレー表示する |
| 生年月日 | YYYY/MM/DD（西暦）で表示 |
| チーム名 | 未入力の場合は「-」（チーム戦なし・パーティ決定方法がシャッフルの場合は未入力もあり得る） |
| パーティ固定 | 固定／非固定 |
| パーティ番号 | パーティ固定が「固定」の場合のみ値が入る（非固定は「-」） |
| 操作 | 編集・不参加（参加に戻す）・削除ボタン |

- 一覧の並び順は既定で登録順。「選手名」「生年月日」「チーム名」「パーティ固定」の見出しクリックで 昇順 → 降順 → 登録順 と切り替える（表示のみで登録順は変わらない。値が同じ場合は登録順。チーム名の昇順では未入力を末尾、パーティ固定の昇順では「固定」→「非固定」の順で固定同士はパーティ番号順）。並べ替え中の列は▲／▼、それ以外の並べ替え可能な列は⇅を表示する。
- 選手が1人もいない場合は「選手が登録されていません」を表示する。

### 登録・編集フォーム項目

ダイアログの見出しは新規登録時「選手情報の新規登録」、編集時「選手情報の編集」とする。

| 項目 | 必須 | 条件 | 入力内容 |
|---|---|---|---|
| 選手名 | ◯ | | テキスト、MAX全角10文字 |
| 生年月日 | ◯ | | テキスト入力（YYYY/MM/DD または和暦略アルファベット S・H・R＋YY.MM.DD。例：S46.05.24）。解析できた場合は入力欄の下に西暦（「→ 1971/05/24」）を表示する |
| チーム名 | | チーム戦あり、またはパーティの決定方法がチームの場合必須（いずれにも該当しない場合も任意項目として表示する） | テキスト、MAX全角10文字 |
| パーティ固定 | ◯ | | チェックボックス「固定」、デフォルト非固定 |
| パーティ番号 | | パーティ固定が「固定」の場合のみ編集可 | 数値、範囲1〜99、デフォルト1 |

### バリデーション
- 選手名：同一大会で重複不可（「選手名「○○」は既に登録されています」）。
- 生年月日：西暦は実在する日付、和暦は元号の適用期間内の日付のみ有効とする。
- 試合結果が1件でも登録されている選手の削除はブロックする（削除ボタンをdisabled）。
- 大会に試合結果が1件でもある場合、既存の全選手のパーティ固定・パーティ番号・チーム名・不参加の変更をブロックする（要件定義書3.3参照）。編集ダイアログではチーム名・パーティ固定・パーティ番号の入力欄をdisabledにし、一覧の「不参加／参加に戻す」ボタンをdisabledにする。一覧下部には「※試合結果が登録されているため、パーティ固定・パーティ番号・チーム名・参加／不参加の変更、および試合結果のある選手の削除はできません。」と表示する（選手名・生年月日の訂正は可能で、組合せ表・スコア表・試合結果は削除しない）。
- 組合せ表が生成済み（試合結果未入力）の状態で、選手の追加・削除、または選手名・生年月日・パーティ固定・パーティ番号・チーム名・不参加のいずれかの変更を保存しようとした場合は確認ダイアログ（「組合せ表・スコア表の削除確認」）を表示し、同意した場合のみ組合せ表・スコア表（と順位表）を削除して保存する（要件定義書2.1。選手名・生年月日のみの変更も対象）。内容に変更がない保存では確認ダイアログを表示しない。

### 操作

| 操作 | 内容 |
|---|---|
| 「+ 新規登録」ボタン | フォームを表示（モーダル）。「保存して閉じる」のほか「追加して続けて登録」ボタンを持ち、押すと入力内容を一覧に追加してダイアログを開いたまま選手名・生年月日をクリアし（「「○○」を一覧に追加しました。続けて入力できます。」と表示）、続けて次の選手を入力できる（チーム名・パーティ固定・パーティ番号は直前の値を引き継ぐ）。追加後はキャンセルボタンが「閉じる」になる |
| 保存ボタン | 新規登録・編集・不参加の切り替え・削除をまとめてサーバーへ反映する。未保存の変更がない間はdisabled。未保存の変更がある間は「未保存の変更があります」と表示する |
| 編集ボタン（行内） | フォームを表示（「保存して閉じる」で一覧に反映） |
| 不参加ボタン（行内） | 選手情報は残したまま「不参加」にし、組合せ表の生成対象から除外する（行をグレー表示し「不参加」ラベルを付ける）。不参加の行では「参加に戻す」ボタンとなり、押すと参加に戻る。保存ボタン押下で確定。試合結果が登録されている場合は変更不可 |
| 削除ボタン（行内） | 一覧表示から除外する（保存ボタン押下で確定） |
| 共通タブ | [大会情報(A3)][競技情報(A4)]へ自由に移動できる |

ダイアログ内の「保存して閉じる」「追加して続けて登録」は一覧への反映のみで、一覧の「保存」ボタンを押すまでサーバーには反映されない（ダイアログ内にその旨を注記する）。

### 遷移先

## A6. 組合せ・スコア表画面

### 概要
パーティ編成（選手の組合せ）・各パーティの開始ホールの確認/手動変更と、ラウンドごとのスコア（8ホール分）の一括入力・確認を1画面で行う（要件定義書3.4〜3.6）。組合せ表自体の生成・再生成はA3・A4・A5共通のボタン群の「組合せ表を作成する」ボタンからのみ行い、本画面には生成ボタンを設けない。

### 表示項目（未生成の場合）
「まだ組合せ表が作成されていません。」のメッセージと、大会情報画面（A3）へ戻るリンク「大会情報画面へ戻る」のみを表示する。

### 表示項目（生成後）

パーティ単位の情報（パーティ番号・開始グループ・開始ホール・スコア入力ボタン）、選手単位の情報（選手名・チーム名・生年月日・年齢・合計スコア）、ラウンド単位の情報（ラウンド・ホール1〜8の打数・小計）を1つの表にまとめて表示する。パーティ番号・開始グループ・開始ホール・スコア入力欄はパーティ内の全行にまたがって表示し、選手名・チーム名・生年月日・年齢・合計欄はその選手のラウンド数分の行にまたがって表示する。各パーティの先頭行には「ホール番号 →」とホール番号1〜8を表示する。

大会終了・閲覧モードの場合は、表の上部に理由（「大会が終了しているため変更できません」「閲覧モードのため変更できません」）を赤字で表示する。表の下部には、ホールインワン変換の算入方法と「スコアを保存しても順位表には自動反映されない」旨を注記する。

| 項目 | 内容 |
|---|---|
| パーティ番号 | パーティ内の全行にまたがって表示（見出しは「パーティ番号」） |
| 開始グループ | パーティ番号と開始ホールの間に表示する。同じ開始ホールのパーティに、パーティ番号の小さい順で1, 2, 3…と付けた番号（開始ホールを1パーティだけで使う場合は1）。保存はせず表示時に算出するため、開始ホールを手動変更すると自動で付け直される |
| 開始ホール | 1〜8の数値。パーティ単位の「変更」ボタンから手動変更できる |
| 選手名・チーム名・生年月日 | 選手単位（チーム名が未入力の場合は「-」。固定/非固定の別は選手情報画面(A5)で確認） |
| 年齢 | 生年月日と大会の開催日を基準に「◯歳◯日」形式で算出して表示する。年齢の加算は法律上の扱い（年齢計算ニ関スル法律・民法143条）に従い、誕生日当日から新しい年齢とする（2月29日生まれは平年は3月1日から）。閏日は実日数に含める |
| ラウンド | 「R1」「R2」…（ラウンド数分の行） |
| ホール1〜8 | ラウンドごとの各ホールの打数（未入力のホールは「ー」表示）。列は開始ホールに関わらず1〜8の順に固定で表示する（要件定義書3.5）。ホールインワン変換ありの場合、打数1のセルに変換値を併記する（例：「1(-2)」。変換値が1の場合は打数と同じため併記しない） |
| 小計 | ラウンドごとの8ホール合計（未入力の場合は「ー」表示） |
| 合計 | 選手の全ラウンド合計（入力済のラウンドのみを合算。1件も入力がない場合は「ー」表示） |

### 操作

| 操作 | 内容 |
|---|---|
| 「パーティ番号」「開始グループ」「開始ホール」見出し | クリックでパーティの表示順を 昇順 → 降順 → 既定（パーティ番号の昇順） と切り替える（表示のみで、組合せ表の内容は変わらない）。開始ホールが同じパーティはパーティ番号の昇順、開始グループが同じパーティは開始ホール → パーティ番号の昇順で並べる（いずれも降順指定時も昇順）。並べ替え中の列は▲／▼、それ以外の列は⇅を表示する |
| 開始ホール「変更」ボタン（パーティ単位） | 開始ホール変更ダイアログ（見出し「パーティ○ の開始ホール変更」）を開く（1〜8のプルダウンで選択し「保存」）。同じ開始グループ（変更前）の他パーティに割り当て済みの開始ホールは選択できない（選択肢をdisabledにし「（同じ開始グループのパーティ○が使用中）」と表示。APIでもエラーとする）。大会ステータスが「終了」の場合・閲覧モードの場合はdisabled |

## A7. 順位表画面

### 概要
「順位表作成」ボタンでその時点のスコアを集計し、総合順位表（個人戦・チーム戦）を表示する（要件定義書3.7）。スコア保存のたびに自動で再集計されるものではなく、管理者が明示的に実行する必要がある。

### 表示項目

| 項目 | 内容 |
|---|---|
| 作成日時 | 最後に「順位表作成」を実行した日時（秒単位）を「作成日時：」として表示する。未作成の場合は「「順位表作成」ボタンを押すと、その時点のスコアを集計して表示します。」を表示する |
| 個人戦順位表（見出し「個人戦 総合順位表」） | 順位・選手名・チーム名（未入力は「-」）・総合スコア・年齢（大会の開催日時点の「◯歳◯日」。生年月日は表示しない）。順位の決定方法（表の上に注記）：1. トータルスコアが小さい、2. 年齢が上、3. じゃんけん。集計対象がいない場合は「集計対象の選手がいません」 |
| チーム戦順位表（チーム戦ありの場合のみ。見出し「チーム戦 総合順位表（合計／平均）」） | 順位・チーム名・人数・合計スコア（順位決定方法が平均の場合は「平均スコア」。小数第2位までの四捨五入で表示）・合計年齢（各選手の「◯歳◯日」の歳・日をそれぞれ合計した表示で、日が365日を超えても歳へ繰り上げない。順位の比較は生年月日から開催日までの実日数の合計で行う）。順位の決定方法（表の上に注記）：1. チームの合計（または平均）スコアが小さい、2. チームの合計年齢が上、3. じゃんけん。集計対象がない場合は「集計対象のチームがありません」 |
| じゃんけん待ち | 決着しない組（同順位）の各行に「じゃんけん待ち」バッジと「手動確定」ボタンを表示する |
| 除外選手の注記 | 「全ラウンド分のスコアが保存されていないため集計対象外：（選手名の一覧）」を表示する（要件定義書3.7参照。不参加の選手は表示しない）。また、画面下部に「※全ラウンド分のスコアが保存済みでない選手は、集計対象から除外されます。」を常に表示する |

### 操作

| 操作 | 内容 |
|---|---|
| 「順位表作成」ボタン | その時点のスコアを集計し、順位表を再生成して表示する（手動確定の内容は引き継がれない。要件定義書3.7参照）。閲覧モード・大会終了中はdisabled |
| 「手動確定」ボタン（じゃんけん待ちの組のみ） | 手動確定ダイアログ（見出し「○○ の最終順位を手動確定」）を開き、「確定する順位（n〜m）」に順位を入力して「確定する」で順位を直接上書きする。入力できる順位は同順位グループの範囲（n〜m）に限り、同じグループ内で既に確定済みの順位とは重複できない。閲覧モード・大会終了中はdisabled |
| 大会運営タブ | [組合せ・スコア表(A6)]へ移動できる |
| 「← 大会情報」「← 大会一覧」リンク | [大会情報(A3)]・[大会一覧(A2)]へ戻る |

大会ステータスが「終了」の場合は、「順位表作成」「手動確定」を行えない（要件定義書2.1。ボタンはdisabledにし、「順位表作成」ボタンの下に「大会が終了しているため変更できません」を赤字で表示する。APIでも拒否する）。終了前に作成した順位表はそのまま閲覧できる。閲覧モードの場合も同様に「閲覧モードのため変更できません」を表示する。

### 遷移先
- 大会運営タブ選択 → A6
- 「← 大会情報」リンク → A3
- 「← 大会一覧」リンク → A2

## A8. バックアップ・リストア画面

### 概要
手動バックアップの実行、バックアップ履歴からの復元、履歴の期間絞り込みを行う（要件定義書4章）。

### 表示項目

| 項目 | 内容 |
|---|---|
| バックアップ履歴一覧 | 作成日時（YYYY/MM/DD HH:MM:SS、秒単位）・契機（手動／ログアウト）。作成日時の新しい順に表示する（保持数は最大20件）。履歴がない場合は「バックアップ履歴はありません」 |
| 期間絞り込み | 開始日〜終了日の指定（カレンダー入力。両端の日を含む。どちらか一方のみの指定も可） |

### 操作

| 操作 | 内容 |
|---|---|
| 「手動バックアップ」ボタン | 即座にバックアップを作成し、履歴に追加する（「バックアップを作成しました」と表示）。閲覧モードではdisabled |
| 「絞込」ボタン | 指定した期間で履歴を絞り込んで表示する |
| 履歴の選択（ラジオボタン） | 復元対象を1件選択する |
| 「復元」ボタン | 復元実行最終確認ダイアログ（見出し「復元の最終確認」）を表示する。履歴を選択していない間、および閲覧モードではdisabled |
| 確認ダイアログの「復元する」ボタン | 選択したバックアップの内容で業務データを完全に上書きする（「復元しました」と表示）。バックアップ履歴自体は上書きしない |

### 遷移先
- 戻るリンク → A2

### ワイヤーフレーム

```
+----------------------------------------------------------------+
| ← 大会一覧                                                        |
| バックアップ・リストア                       [ 手動バックアップ ]    |
+----------------------------------------------------------------+
| 開始日 [____] 〜 終了日 [____]  [絞込]                            |
+----------------------------------------------------------------+
| ( ) 2026/11/16 20:00:00  手動                                    |
| (●) 2026/11/15 18:30:12  ログアウト                              |
+----------------------------------------------------------------+
|                                                      [ 復元 ]     |
+----------------------------------------------------------------+
```
