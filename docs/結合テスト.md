# 結合テストケース一覧

## 目的

本ドキュメントは、`CLAUDE.md` のテスト方針に基づき、API Routes・ファイルベースJSONストア・画面間の連携・ブロック系ルール・認証・バックアップなど、複数コンポーネントを跨いだ振る舞いを検証する結合テストケースを列挙する。

- 本書はテストケースの仕様である。実行可能なテストコードは `tests/integration/*.spec.ts`（Playwright。開発サーバーに対して実際の画面操作・API呼び出しを行う）として実装する。
- 単体で閉じるコアロジックの検証は `docs/ユニットテスト.md` を参照。
- 画面ID・URLは `docs/画面仕様書.md` に準拠する。
- 実行コマンド：`npm run test:integration`（`playwright.config.ts` が専用ポート3100・専用データ保存先 `.test-data` で開発サーバーを自動起動する）。
- 各テストは自身で大会等のデータをAPI経由で作成し、他テストのデータに依存しない。

| ファイル | 対象 |
|---|---|
| `tests/integration/auth.spec.ts` | 1. 認証・閲覧モード・ログアウト |
| `tests/integration/tournament.spec.ts` | 2. 大会一覧・大会情報 |
| `tests/integration/competition.spec.ts` | 3. 競技情報 |
| `tests/integration/players.spec.ts` | 4. 選手情報 |
| `tests/integration/pairings.spec.ts` | 5. 組合せ表生成、6. 組合せ・スコア表 |
| `tests/integration/status.spec.ts` | 7. 大会ステータス |
| `tests/integration/rankings.spec.ts` | 8. 順位表 |
| `tests/integration/backup.spec.ts` | 9. バックアップ・リストア |
| `tests/integration/api.spec.ts` | 10. API共通 |
| `tests/integration/variations.spec.ts`（`tests/integration/fixtures/`） | 11. サンプルデータによるバリエーション |
