# インストール手順書（macOS版）

「グランドゴルフしようよ」をMacにインストールし、起動するまでの手順です。

## 1. 動作環境

| 項目 | 内容 |
|---|---|
| OS | macOS 12（Monterey）以降 |
| CPU | Apple シリコン（M1/M2/M3/M4 等）または Intel |
| ディスク空き容量 | 1GB以上 |
| インターネット接続 | 不要（インストール後はオフラインで動作します） |
| その他 | Node.js などの追加ソフトのインストールは不要です（アプリに同梱されています） |

## 2. フォルダの内容

この `Mac` フォルダをフォルダごとUSBメモリ等でコピーして使用します。

| ファイル | 内容 |
|---|---|
| `GrandGolf-1.0.0-mac-arm64.dmg` | Apple シリコン搭載Mac用のインストーラ |
| `GrandGolf-1.0.0-mac-x64.dmg` | Intel搭載Mac用のインストーラ |
| `インストール手順書.md` | 本書 |
| `操作手順書.md` | アプリの操作手順書（アプリにも同梱され、メニュー「ヘルプ」→「操作手順書を開く」で開けます） |

お使いのMacのCPUは、画面左上のアップルメニュー →「このMacについて」の「チップ」（Apple M1 等）または「プロセッサ」（Intel 等）で確認できます。

## 3. インストール手順

1. お使いのMacに合ったdmgファイル（上表）をダブルクリックして開きます。
2. 表示されたウィンドウで、「グランドゴルフしようよ」のアイコンを「Applications（アプリケーション）」フォルダのアイコンへドラッグ＆ドロップします。
3. コピーが終わったら、ウィンドウを閉じ、Finderのサイドバーに表示されているdmg（「GrandGolf 1.0.0」）の取り出しボタンを押します。
4. **検疫属性の解除**（初回のみ・必須）：本アプリはApple Developer IDによる正式な署名・公証を行っていないため、インターネットやUSBメモリ経由でコピーしたアプリは、そのままでは「"グランドゴルフしようよ"は壊れているため開けません」または「開発元が未確認のため開けません」と表示されて起動できません。以下の手順で解除してください。
   1. 「アプリケーション」→「ユーティリティ」→「ターミナル」を開きます。
   2. 次のコマンドを入力（コピー＆ペースト）して **return** キーを押します。

      ```
      sudo xattr -cr "/Applications/グランドゴルフしようよ.app"
      ```

   3. Macのログインパスワードを求められたら入力して **return** キーを押します（入力中の文字は表示されません）。
   4. エラーが表示されずに次の行に戻れば完了です。ターミナルを閉じます。

## 4. 初回起動

1. **初回起動は、管理者権限のあるMacアカウントで行ってください。** 大会データの保存先フォルダ（`/Library/Application Support/グランドゴルフしようよ`）は、同じMacの全アカウントで共有するため、作成に管理者権限が必要です。管理者権限の無いアカウントで初回起動すると「データ保存先フォルダを作成できませんでした」と表示されて終了します。
   - 2回目以降の起動を管理者権限の無いアカウントで行う場合は、管理者アカウントでターミナルから次のコマンドを実行し、保存先フォルダへの書き込みを許可してください。

     ```
     sudo chmod -R a+rwX "/Library/Application Support/グランドゴルフしようよ"
     ```

2. 「アプリケーション」フォルダ（またはLaunchpad）から「グランドゴルフしようよ」を起動します。
3. 数秒〜十数秒でログイン画面が表示されます。
4. 次の初期管理者アカウントでログインします。

   | 項目 | 初期値 |
   |---|---|
   | ID | `TakunishiSC` |
   | パスワード | `0962778801` |

5. **ログイン後、速やかにID・パスワードを変更してください。** ログイン画面の「ログイン情報を変更する」から変更できます（操作手順書「1. アプリの起動とログイン」参照。パスワードは8文字以上）。

以降の操作方法は、`操作手順書.md`（またはアプリのメニュー「ヘルプ」→「操作手順書を開く」）を参照してください。

## 5. データの保存場所

| 内容 | 保存場所 |
|---|---|
| 大会データ・管理者アカウント | `/Library/Application Support/グランドゴルフしようよ/` |
| バックアップ | 同フォルダ内の `backups/` |
| 動作ログ（不具合調査用） | 同フォルダ内の `logs/server.log` |

- データは同じMacの全アカウントで共有されます。
- 選手の氏名・生年月日などの個人情報を含むため、上記フォルダを他人に渡したり、共有フォルダに置いたりしないでください。

## 6. アップデート（新しいバージョンへの更新）

1. 起動中のアプリを終了します。
2. 新しいバージョンのdmgで「3. インストール手順」を行い、「アプリケーション」フォルダのアプリを置き換えます（「置き換える」を選択）。
3. 「3. インストール手順」の手順4（検疫属性の解除）を再度行います。

大会データは「5. データの保存場所」に保存されているため、アプリを置き換えても引き継がれます。念のため、更新前にアプリの「バックアップ」画面で手動バックアップを作成しておくことをお勧めします。

## 7. アンインストール

1. 起動中のアプリを終了します。
2. 「アプリケーション」フォルダの「グランドゴルフしようよ」をゴミ箱に入れます。
3. 大会データも削除する場合は、管理者アカウントでターミナルから次のコマンドを実行します（**元に戻せません**）。

   ```
   sudo rm -rf "/Library/Application Support/グランドゴルフしようよ"
   ```

## 8. うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「壊れているため開けません」「開発元が未確認」と表示される | 「3. インストール手順」の手順4（検疫属性の解除）を行ってください |
| 「データ保存先フォルダを作成できませんでした」と表示される | 管理者権限のあるアカウントで起動してください（「4. 初回起動」参照） |
| 「アプリ内部のサーバーを起動できませんでした」と表示される | アプリを終了して再度起動してください。改善しない場合は、表示されたログファイル（`logs/server.log`）を導入時の担当者にお送りください |
| 起動直後にアプリが終了してしまう（macOS 26以降の一部のApple シリコン搭載Mac） | Electron（アプリの土台となるソフトウェア）側の既知の不具合の可能性があります。最新バージョンのアプリが公開されていれば更新してください |
| ID・パスワードを忘れた | 操作手順書の「ID・パスワードを忘れた場合」を参照してください |
