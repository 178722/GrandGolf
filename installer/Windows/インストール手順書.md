# インストール手順書（Windows版）

「グランドゴルフしようよ」をWindows PCにインストールし、起動するまでの手順です。

## 1. 動作環境

| 項目 | 内容 |
|---|---|
| OS | Windows 10 / Windows 11（64ビット版） |
| ディスク空き容量 | 1GB以上 |
| インストール時の権限 | 管理者権限（インストール中に「ユーザーアカウント制御」の確認が表示されます） |
| インターネット接続 | 不要（インストール後はオフラインで動作します） |
| その他 | Node.js などの追加ソフトのインストールは不要です（アプリに同梱されています） |

## 2. フォルダの内容

この `Windows` フォルダをフォルダごとUSBメモリ等でコピーして使用します。

| ファイル | 内容 |
|---|---|
| `GrandGolf-1.0.0-win-x64-setup.exe` | インストーラ |
| `インストール手順書.md` | 本書 |
| `操作手順書.md` | アプリの操作手順書（アプリと一緒にインストールされ、メニュー「ヘルプ」→「操作手順書を開く」で開けます） |

## 3. インストール手順

1. `GrandGolf-1.0.0-win-x64-setup.exe` をダブルクリックします。
2. 「WindowsによってPCが保護されました」（Microsoft Defender SmartScreen）と表示された場合は、「詳細情報」をクリックし、表示された「実行」ボタンを押します。
   - 本アプリはコード署名証明書による署名を行っていないため、この表示が出ます。アプリの動作には影響ありません。
3. 「ユーザーアカウント制御」で「このアプリがデバイスに変更を加えることを許可しますか？」と表示されたら「はい」を押します。
4. インストールウィザードが表示されます。画面の指示に従って進めます。
   - インストール先フォルダは変更できます（既定：`C:\Program Files\グランドゴルフしようよ`）。
   - PCの全ユーザーが利用できる形でインストールされます。
5. 「完了」を押すとインストールが終わります。デスクトップとスタートメニューに「グランドゴルフしようよ」のショートカットが作成されます。
6. 操作手順書は、インストール先フォルダの `resources\操作手順書.md` にインストールされます（アプリのメニュー「ヘルプ」→「操作手順書を開く」でも開けます。メニューが表示されていない場合はAltキーを押してください）。

## 4. 初回起動

1. デスクトップまたはスタートメニューの「グランドゴルフしようよ」を起動します。
2. 初回起動時に「Windowsセキュリティの重要な警告」（ファイアウォール）が表示された場合は、「キャンセル」を押して構いません（アプリはこのPC内でのみ通信し、ネットワークからの接続は受け付けません）。
3. 数秒〜十数秒でログイン画面が表示されます。
4. 次の初期管理者アカウントでログインします。

   | 項目 | 初期値 |
   |---|---|
   | ID | `TakunishiSC` |
   | パスワード | `0962778801` |

5. **ログイン後、速やかにID・パスワードを変更してください。** ログイン画面の「ログイン情報を変更する」から変更できます（操作手順書「1. アプリの起動とログイン」参照。パスワードは8文字以上）。

以降の操作方法は、`操作手順書.md`（またはアプリのメニュー「ヘルプ」→「操作手順書を開く」）を参照してください。

## 5. データの保存場所

| 内容 | 保存場所 |
|---|---|
| 大会データ・管理者アカウント | `C:\ProgramData\グランドゴルフしようよ\` |
| バックアップ | 同フォルダ内の `backups\` |
| 動作ログ（不具合調査用） | 同フォルダ内の `logs\server.log` |

- `C:\ProgramData` は隠しフォルダです。エクスプローラーのアドレス欄に `%ProgramData%\グランドゴルフしようよ` と入力すると開けます。
- データは同じPCの全ユーザーで共有されます。
- 選手の氏名・生年月日などの個人情報を含むため、上記フォルダを他人に渡したり、共有フォルダに置いたりしないでください。

## 6. アップデート（新しいバージョンへの更新）

1. 起動中のアプリを終了します。
2. 新しいバージョンのインストーラで「3. インストール手順」を行います（上書きインストールされます）。

大会データは「5. データの保存場所」に保存されているため、更新しても引き継がれます。念のため、更新前にアプリの「バックアップ」画面で手動バックアップを作成しておくことをお勧めします。

## 7. アンインストール

1. 起動中のアプリを終了します。
2. 「設定」→「アプリ」→「インストールされているアプリ」（Windows 10では「アプリと機能」）で「グランドゴルフしようよ」を選び、「アンインストール」を押します。
3. 大会データも削除する場合は、`%ProgramData%\グランドゴルフしようよ` フォルダを削除します（**元に戻せません**）。

## 8. うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「WindowsによってPCが保護されました」と表示されてインストールできない | 「詳細情報」→「実行」を押してください（「3. インストール手順」の手順2） |
| 「アプリ内部のサーバーを起動できませんでした」と表示される | アプリを終了して再度起動してください。改善しない場合は、表示されたログファイル（`logs\server.log`）を導入時の担当者にお送りください |
| ウイルス対策ソフトにより起動がブロックされる | ウイルス対策ソフトの設定で、インストール先フォルダを除外（許可）してください |
| ID・パスワードを忘れた | 操作手順書の「ID・パスワードを忘れた場合」を参照してください |
